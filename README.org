#+title: misskey.el
#+options: toc:nil num:nil

~misskey.el~ is an Appkit-backed Emacs client for Misskey-compatible
servers.  It provides timelines, threads, profiles, search, notifications,
media previews, multi-note composition with Drive attachments, and
contextual Note and user actions.

See the [[file:docs/misskey.org][manual]] for installation and authorization,
browsing and writing workflows, failure recovery, configuration, and
implementation boundaries.

Start browsing with ~M-x misskey-home~.  The ~?~ browsing menu and
~C-c C-o~ draft menu expose the available operations; optional Evil
integration supplies client-local bindings without changing global maps.
